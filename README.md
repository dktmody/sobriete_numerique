# Audit de la fonctionnalité "Trajet" - Île-de-France Mobilités

Ce projet présente un **audit de la fonctionnalité "Trajet"** du site [Île-de-France Mobilités](https://www.iledefrance-mobilites.fr), réalisé dans le cadre d'une démarche de **sobriété numérique** et de **conception responsable**.

## 📄 Contenu du projet

Le site se compose d'une seule page HTML qui contient :

- Une **présentation** de la fonctionnalité.
- Un **audit de conception responsable** avec :
  - Points forts
  - Points à améliorer
- Une section **recommandations**.
- Les résultats de **3 audits automatisés** :
  - Lighthouse
  - GreenIT
  - WAVE
- Une section **informations complémentaires**.
- Un **sommaire avec navigation par ancres**.
- Des **images interactives** : en cliquant sur chaque image d'audit, celle-ci s'affiche en grand format.
